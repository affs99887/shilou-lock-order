# 拾漏锁单 Mac 5 秒静音版

版本：0.6.2-quiet5s.1，基于 0.6.2-minute.6。

- 本地提示音调用已注释，首次启动、读取旧设置和保存设置均关闭声音。系统通知、Bark 和飞书仍按原逻辑发送。
- 桌面监控基础间隔为 5 秒，保留原有 ±20% 随机浮动，每轮查询完成后通常等待约 4–6 秒。桌面请求预算每 5 秒恢复一次额度，避免原先每分钟恢复一次的设置拖慢持续查询。
- 请求耗时、多城市／多批次查询、重试和限流退避仍会增加实际间隔；5 秒不是所有情况下的严格墙钟周期。
- 分期卡片、选中期数、原生下拉框、侧栏、快捷入口、下单提示区和错误提示使用深浅主题配色。原生日期、下拉和勾选控件通过 `color-scheme` 跟随主题。
- 沿用现有设置目录，启动后不会自动开启监控或选购。使用新版前请退出旧版。

构建前先运行 `python3 scripts/mac-source.py` 更新随应用附带的源码，再运行 `npm run tauri -- build --bundles app`。
