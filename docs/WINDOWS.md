# 拾漏锁单 Windows

Windows 0.6.2-auto.13 基于已同步 Mac 0.6.2-auto.11 的 auto.12，保留界面、监控内核、分期预设、选购判断和下单保护，包括按型号取货日期规则、门店／时段恢复及人工步骤双提醒。
Windows 浏览器适配复用抢先购的 `consumer/edge_browser.py`；使用专属 Edge 用户目录，不接管日常浏览器标签。

## 使用

Windows 10/11 64 位（x64），需要 Microsoft Edge。双击安装程序，按提示安装。
软件内置 Python 与浏览器控制组件，无需自行安装 Python。缺少 WebView2 时安装程序会联网补齐。

1. 在监控目标中添加门店、机型、容量与颜色。
2. 在选购方案中填写联系资料，选择省市区、预算、数量、保障和付款方案。
3. 手机提醒中粘贴 Bark 链接，保存并测试。
4. 先测试演练，再点「启用有货自动选购」，库存监测会随之一起开始。演练不提交订单。
5. 大陆正式自动下单需在方案里勾选「自动下单，等待本人支付」，之后点启用或手动开始不再弹窗确认；登录、验证码、授信、签约与付款由本人完成。

中国大陆、香港、台湾、日本、新加坡、澳大利亚、马来西亚使用同一界面选择。海外选购与 Mac 一样仍为候选适配，使用当地资料和币种，不套用大陆分期；海外付款、分期及最终提交由本人操作，不承诺待支付锁单。海外完整官网流程尚未验收。

「按型号」取货规则：Duo 遵守用户设置的指定日期，其他机型选择官网最早可取日期和时段；不会因混合监控而扩大 Duo 日期范围。设置不自动修改。

需要登录、验证码、地址手选或付款处理时，软件醒目提示，并通过已配置的 Bark 提醒；同一步骤不反复推送。Windows 提示指向专属 Edge，而不是 Safari。

选配恢复：打开页面的短时导航超时进入只读核对，不立即终止，也不重复打开；窗口无法前置与专属页面丢失分开处理。型号／颜色／容量暂时禁用不再当作缺货，逐步等待选项就绪，持续未就绪最多 30 秒后交给本人处理。明确的缺货证据仍结束当前尝试。未知结果、真正网络错误或失去目标页面仍保留现场，绝不盲目加购。

软件与 Edge 保持运行、电脑保持联网和唤醒。隐藏窗口后监测仍可运行。
缺货或访问失败不代表下单成功；以 Apple 官方订单状态和支付期限为准。

Windows 联系资料通过当前 Windows 用户的 DPAPI 加密，不复制 Mac 钥匙串、Cookie 或账号密码。
新用户在选购方案内填写，已有资料可点“读取已保存资料”修改。
旧抢先购方案可通过原有“导入原抢先购方案”按钮导入。

安装包未购买 Windows 代码签名证书；系统可能提示未知发布者。仅使用可信来源提供的文件。
安装目录的 `resources/OpenSource` 附完整对应源码、LICENSE 与 NOTICE，保留 GPL-3.0 许可。

## 构建

在 Windows x64 上先运行 `scripts/windows-tools.ps1` 安装构建依赖；运行 `scripts/windows-source.py` 生成对应源码，放入 `src-tauri/resources/OpenSource/Source.tar.gz`，然后运行 `scripts/windows-build.ps1`。
`tauri.windows.conf.json` 自动覆盖 Windows 组件名称、版本及 NSIS 安装选项；Mac 配置不变。

构建验证包含前端回归、Windows 原生 DPAPI/互斥锁测试、打包组件自测及 UTF-8 IPC 测试。
真实 Apple 登录、库存和订单创建的验收必须单独记录；离线模拟测试不作为实购成功证据。

Windows auto.12：保留应用内确认框、首次资料编辑、全款／分期、Bark、原监控表及近期查询。新版不自动启动监控或正式下单；原资料保留。

Windows auto.13：专属 Edge 主文档及商店 fetch/XHR 返回 403、429、541 时，阻止后续写操作并将受限状态传递给库存监控，监控停止后须先验证选购页恢复。真正的 HTTP 404 单独识别。新增本地 `checkout-diagnostics.json`，仅包含固定步骤、动作枚举、时间和状态码；无 URL、联系人或 Cookie。查询间隔不变。此次现场确认是商品页表单提交返回 541，不能把修复联动逻辑描述成已解除 Apple 访问限制。

另一次授权复测记录到打开购物袋时 `ERR_NETWORK_CHANGED`。针对商品基础入口和购物袋的失败 GET，最多恢复一次；导航超时仍只读等待，不重复导航。其他路径、DOM 点击、加购与订单写入均不重放。网络切换、DNS、代理与断网错误通过固定错误码提示，不输出原始 URL。
