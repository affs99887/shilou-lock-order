# Mac 0.6.2-auto.14

- “选购前清空购物袋”开启时优先执行清空，包括已有同款商品；逐项移除并回读确认后，重新按本次库存目标选购。关闭该设置时，才允许核验并复用完全匹配的单件商品。
- 修复官网使用图标显示分期渠道名称时，无法识别微信分付、花呗及银行分期的问题。
- 已选明确分期渠道后，不再把“通过支付宝选择更多银行”的搜索框误判为必填联系资料；银行卡号等真正的付款字段继续保留校验。
- 分期核对数据为空时显示未确认提示，避免空数据引发执行异常。
- 保留多个有货目标仅推进一个任务的互斥控制；补充并发测试。异常时保存错误类型、代码位置和记录编号，不保存联系人、网页全文或异常参数。

说明：用户反馈的旧版通用异常没有保留堆栈，仅能确认最后到达订单核对页，不能据此认定由多个同款库存导致。上述缺陷均有独立复现或官网实测依据。测试中的最终订单命令在本地拦截，不创建订单或付款。
