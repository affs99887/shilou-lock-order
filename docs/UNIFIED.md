# 拾漏锁单 0.6.2-auto.11 合并版

本版合入国际候选版 0.6.2-intl.2 的七地区目录、地区资料编辑、本地币种预算，以及登录、付款、地址等人工步骤的软件与 Bark 提醒。使用原拾漏锁单的应用标识与设置目录，无须在两个应用之间切换；旧国际候选版的隔离资料不会自动导入。

## 按型号选择取货日期

选购方案新增「按型号 · Duo 指定日期，其他最早可取」：

- Duo 仅在填写的指定日期中按顺序选择。当前用户设为 2026-10-23、2026-10-24、2026-10-25；没有范围内日期时不改选范围外日期。
- 其他型号选择官网当前最早可取日期及最早可用时段。判断依据是实际命中的监控型号，包含所有容量、颜色与门店，不沿用方案里以前保存的机型。
- 首页始终显示当前规则。指定日期在策略切换时保留，按型号模式下直接展示 Duo 日期输入框。
- 库存“有货”仍表示官方库存接口有货；实际日期资格在官网取货步骤核验，有货提示本身不证明符合日期范围。
- 原「所有型号指定日期」「所有型号最早可取」仍可选择，已有设置不自动改变；本机根据用户明确选择启用按型号模式。

## 国际功能范围

中国大陆、香港、台湾、日本、新加坡、澳大利亚、马来西亚在同一个软件中选择，国际功能仍沿用 intl.2 的候选适配范围：地区和币种严格匹配，地区资料分别保存；海外付款、分期与最终提交由本人完成。切换地区须重新填写当地币种预算。无法明确识别的当地日期提示本人处理，不猜测日期。

国际适配的完整官网选购流程尚未验收。国内最终页无法核对订单完整信息时仍保留现场，本次日期规则回归不会创建新的真实订单或付款。前一笔已生成订单的防重复记录保留。
