# 拾漏锁单 Mac 一分钟静音版

版本：0.6.2-minute.7。

- 恢复 `0.6.2-minute.6` 的一分钟监控策略：基础间隔 60 秒，保留 ±20% 随机浮动，每轮查询完成后通常等待约 48–72 秒。
- 请求预算恢复为原版默认值：每条线路容量 20，每 60 秒恢复一个额度。请求耗时、多组查询、失败退避和冷却仍可能拉长实际间隔。
- 保留本地静音和深色模式修复；系统通知、Bark 和飞书按原逻辑工作。
- 查询失败显示“未知”，与尚未轮到的“待查询”分开。日志和提示区显示具体 HTTP 错误及冷却详情，库存统计单独列出查询异常。
- 被拦截后首次冷却 5 分钟，到期探测仍被拦才依次延长到 10、20、30 分钟。冷却期间不会向受影响线路发起库存查询，重复状态检查日志不等于新的 HTTP 请求。这是客户端策略，不代表 Apple 告知的限制时长。
- HTTP 429 和 5xx 的退避保留具体状态码；请求预算不足时单独说明本轮等待秒数。冷却提示不再把所有拦截情况固定写成 HTTP 541。
- 沿用应用标识、设置目录和钥匙串标识。旧设置中的轮询间隔会在读取时恢复为 60 秒，其他监控配置及通知地址保持原值；不会自动启动监控或选购。使用前请退出旧版。

构建前运行 `python3 scripts/mac-source.py`，再运行 `npm run tauri -- build --bundles app -- --locked`。
