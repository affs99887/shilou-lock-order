# 拾漏锁单 Mac 换 IP 5 秒版

版本：0.6.2-rotate5s.1，基于 0.6.2-minute.7。

## 解决什么问题

Apple 按「出口 IP」（你的网络在 Apple 看来的地址）和「会话」（浏览器 cookie）累计库存查询次数：同一个 IP 连续查大约 30 次就会被拦（HTTP 541），之后十几分钟一直被拦。所以 5 秒一次的版本（0.6.2-quiet5s.1）用着用着就查不动了，0.6.2-minute.7 只好退回 60 秒。

本版新增「隧道代理模式」：每次查询都从代理商那里换一个新的出口 IP，并用一份全新的 cookie，次数攒不起来，间隔才能调到 5 秒。

## 怎么用

1. 准备一个**隧道代理**：代理商给一个固定地址，你每次连它，它都替你换一个出口 IP。要选「按请求换 IP」（也叫「每次请求更换 IP」），不要选几分钟才换一次的。住宅（家庭宽带）IP 比机房 IP 更不容易被 Apple 拦。拿到形如 `http://用户名:密码@隧道域名:端口` 的地址，`socks5://` 开头的也可以。
2. 打开「手机提醒」页，找到「代理线路」：
   - 「代理地址」填上面那一行；
   - 打开「每次查询换一个出口 IP（隧道代理）」；
   - 「查询间隔」选 5 秒；
   - 点「保存代理设置」，看到「已生效：每 5 秒查一次，每次换一个出口 IP，不走本机网络」就对了。
3. 开始监测后看「最近查询」：没有「连不上代理」「出口 IP 被拦截」之类的提示，说明代理在正常工作。

## 打开后具体怎么查

- 每次查询都新建一条到代理的连接（代理商随之分配一个新 IP），先打开一次购物袋页拿到 cookie（代码里叫「暖场」），再查库存。两步走同一条连接，所以是同一个 IP。
- 某个 IP 被拦：当场换一个 IP 重查，最多再换 2 次；不会像本机网络那样整条线路冷却 5～30 分钟。
- 连换 3 个 IP 都被拦：这一轮库存记为「未知」，提示可能要换一家代理；整轮都失败时，下一轮的间隔会逐步加倍（最多 8 倍），代理恢复后自动回到 5 秒。
- 本机网络完全不参与查询，留给自动选购用的浏览器。
- 代理连不上时：库存显示「未知」并提示「连不上代理」，**不会**偷偷改用本机网络。
- 关掉这个开关，或者填的代理地址都无效：自动回到 60 秒、用本机网络查询，和 0.6.2-minute.7 一样。

## 需要知道的限制

- 不能保证一定不被拦：Apple 也可能按代理商的整段 IP 或请求特征判断。一直出现「出口 IP 被拦截」时，换一家代理或换住宅 IP。
- 每次查询多打开一次购物袋页，流量比原来多；按流量计费的代理请留意用量。
- 自动选购仍在本机浏览器里、用本机网络进行。选购页面被 Apple 拒绝（541 / 403 / 429）时，软件仍按原规则暂停监控，本版没改这条。

命令行版同样支持：`apw watch ... --proxy '<隧道代理地址>' --rotate-proxies --interval 5`，见 [cli.md](cli.md)。

构建前运行 `python3 scripts/mac-source.py`，再运行 `npm run tauri -- build --bundles app -- --locked`。
