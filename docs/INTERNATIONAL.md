# 国际选购候选版 0.6.2-intl.2

## 当前范围

Mac、Safari、iPhone。监控范围与上游一致：中国大陆、香港、台湾、日本、新加坡、澳大利亚、马来西亚。国内继续用原适配器；另外六个地区有独立的实验适配器，**尚未获得官网完整流程通过结论，不是可对外销售的全地区正式支持版**。

原监控内核、查询周期、冷却策略、Bark 以及国内分期不改。不开代理轮换或任何访问限制规避。

## 操作

1. 在捡漏中心选择当地国家／地区，添加当地 iPhone 配置和门店。
2. 选购方案里另选同一地区，填写**当地货币总预算**。切换地区会把旧预算清零，不自动做汇率换算，也不默认把人民币当成日元等货币。
3. 为当地地区填写并保存联系资料。海外与大陆分别存于钥匙串；无银行卡、密码、验证码字段。日本需假名，当地电话与邮编按该地区校验。
4. 先测试演练。进入付款、需要登录、银行卡验证、分期或页面无法唯一匹配时，软件显示醒目处理卡片，并通过已配置的 Bark 通知本人。未知库存不会触发选购。
5. 开启监测后才启用选购。只执行当前选购地区的目标。只推进一个选购流程；与旧版共用执行锁，不要同时运行两版监控。

本轮海外付款统一交给当地官网本人选择，不复制大陆支付宝／花呗等预设。海外订单提交可能触发信用卡冻结资金或授信，不等价于国内的“未支付锁单”；因此禁止海外自动提交、付款、签约。演练也不提交。

## 人工步骤双提醒

- 所有六个海外地区使用同一套人工步骤通知：登录／验证码、付款／分期、订单核对、联系地址、门店／日期、AppleCare、购物袋及未知页面。
- 软件卡片与 Bark 使用同一条地区、标题和处理原因；不包含个人资料、Cookie、会话网址或验证码。
- 登录首次识别就提醒，并保持只读等待；验证完成后重新识别。其他步骤保留现场，按提示本人处理后点击“人工处理后继续”。
- 同一文档、同一步骤、同一原因只通知一次；反复点击继续不会刷屏。进入不同步骤或完成操作后再次遇到人工处理会重新提醒。
- 后台通知不阻塞软件更新；发送失败保留处理卡片并提示检查 Bark，不伪报已送达，不擅自继续付款。
- 停止任务后不产生新的人工提醒；已经发送的手机通知无法撤回。
- 本次仅完成离线通知与界面回归，没有用真实 Bark 密钥发送通知，也没有完成海外官网付款实测。

## 实现与保护

- `checkout-regions.json` 与监控七地区表做一致性测试。
- `checkout-catalog.json` 由现有官方离线商品／门店目录生成，不凭中文颜色名拼 SKU。目录未收录的新配置安全交给本人，而不是猜测。
- 严格绑定本地区 Apple 域名和路径。大陆联系方式不进入国外官网，登录页面不注入资料。
- 购物袋必须核验准确 SKU、官方数量选项、保障、本地币种和总价后才结账；空解析结果不算空购物袋。
- 写操作具有文档指纹、单次回执与步骤账本。加入结果不明先看购物袋，不重复加入。
- 明确售罄结束本次尝试，等待新的有效库存；访问限制、会话过期、未知页面、手动地址选择与缺货分开处理。不会擅自改变门店、日期、保障或配送方式。
- 海外 AppleCare 以及日期控件不明确时需本人处理；日期仅识别可明确核验的 ISO 选项，不猜“明天”的当地日期。

## 隔离发布

独立 Bundle ID `local.apple-pickup-watcher.auto.international`。监控资料在 `apple-pickup-watcher-international`，选购资料在 `ApplePickupWatcherInternational`，不改当前国内软件及设置，不自动恢复任务。没有替换本机稳定版。

构建：先运行 `checkout/build.py --international`、`scripts/mac-source.py --international`，再运行 `npm run tauri -- build --features international-preview --config src-tauri/tauri.international.conf.json --bundles app --no-sign`。专用后台文件与构建目录不覆盖国内后台产物。构建后做本地 ad-hoc 签名与验收。
