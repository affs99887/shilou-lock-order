# Mac 0.6.2-auto.12

- 修复部分门店查询失败时，其他门店的有效有货结果也无法触发自动选购的问题。库存有效期、型号映射和重复下单保护继续逐条核验。
- 购物袋已有完全相同的单行商品和数量时复用现有购物袋，再核对预算和保障，避免重复移除及加购。购物袋更新中或存在官网错误时暂停操作。
- 修复复用购物袋后仍使用商品入口超时计时，导致取货选择中途停止的问题。
- 官网跳过已保存的取货、联系人或付款步骤时，通过唯一的官方更改入口重新核对缺失步骤。等待切换完成，不重复点击。
- “最早可取”模式下，仅在本次取货门店、日期和时段已经核验，且最终页为单件目标商品、明确显示“取货日期待付款完成后确定”时，允许继续核对并在正式授权模式下提交。最终可取时间仍以付款后的官网结果为准。指定日期模式不使用此回退，Duo 23–25 号规则保持严格。
- 分开显示页面不存在、会话失效和访问被拦。暂停流程明确显示“已暂停，需要处理”，不再显示“正在执行”。
- HTTP 拒绝状态优先于官网错误页路径，避免把拦截模板误当成普通 404。

查询基础间隔保持用户原设置。库存查询的请求预算与 5/10/20/30 分钟冷却不代表 Apple 保证解除限制的时长。

验证范围、现场回读和安装校验记录位于本地 `checkout/qa-pickup-stability/`；不打入客户源码包。测试演练不会创建订单或付款。
