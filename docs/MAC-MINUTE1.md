# 拾漏锁单 Mac 桌面发行构建

版本：0.6.2-minute.5，基于 Mac 0.6.2-auto.14。

- 基础监测间隔固定为 60 秒，首次使用及读取旧设置时均生效。
- 库存列表不显示扫描频率、下一轮扫描秒数或最后检查时间；最近查询记录、记录时间及异常提示保留。
- 监测访问限制在主界面显示“调度保护已启用”，库存仍为未知；最近查询保留具体原因，保护与恢复逻辑不变。
- 主界面去掉“查不到”统计，尚未取得有效结果的库存行统一显示“正在查询”；仅改变展示，后台未知状态与到货判定保持不变。
- 请求预算、间隔抖动、失败退避、冷却、库存判断、Bark 和自动选购机制保持不变；实际查询等待仍可能超过基础间隔。
- 使用原来的设置和联系资料。切换版本前退出旧版；不会自动开启监测或选购。

构建：先运行 `python3 scripts/mac-source.py`，再运行 `npm run tauri -- build --bundles app`。选购组件重新打包，新增手动有货目标入口；保留原有选购、订单保护和浏览器适配。

有货行的“立即选购”使用已保存方案和指定目标。Rust 从真实库存快照匹配目标；手动入口允许使用列表保留的有货结果，在官网重新核验，不伪造时间戳。已有 arming/reservation/stop 时请求无效；自动库存入口的时效规则不变。
